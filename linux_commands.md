# Linux Commands - My Notes

| Command | What it does | Example |
|---|---|---|
| `pwd` | Shows the current directory | `pwd` |
| `ls` | Lists files and folders | `ls -la` |
| `cd` | Changes directory | `cd Documents` |
| `mkdir` | Creates a folder | `mkdir lab` |
| `touch` | Creates an empty file | `touch notes.txt` |
| `cp` | Copies a file | `cp a.txt b.txt` |
| `mv` | Moves or renames a file | `mv a.txt c.txt` |
| `rm` | Deletes a file | `rm old.txt` |
| `cat` | Shows file contents | `cat notes.txt` |
| `grep` | Searches text inside files | `grep "error" log.txt` |
| `chmod` | Changes file permissions | `chmod 755 script.sh` |
| `ping` | Tests network connection | `ping 8.8.8.8` |
| `ip a` | Shows IP addresses | `ip a` |
| `whoami` | Shows the current user | `whoami` |
| `sudo` | Runs a command as administrator | `sudo apt update` |
